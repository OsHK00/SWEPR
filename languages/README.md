# Idiomas

SWEPR elige inicialmente el idioma de Windows. También puedes cambiarlo en Configuración. Las traducciones se leen desde la carpeta `languages` junto al ejecutable. Para agregar uno, crea un archivo JSON con el código del idioma, por ejemplo `fr.json` o `fr-CA.json`, usando las mismas claves que `en.json` y agrega `"language_name": "Français"` para mostrar su nombre en el selector.

Las claves faltantes se muestran en inglés. No hace falta recompilar: basta con colocar el archivo en esa carpeta y reiniciar SWEPR.
